# voronoi_checker

PDF または PPTX 形式のスライドからボロノイ図を自動検出し、発生点（ジェネレータ）数が不足しているファイルをリストアップするツールです。

## 必要なライブラリ

```bash
pip install PyMuPDF opencv-python numpy scipy openpyxl python-pptx
```

## 使い方

### フォルダごと一括チェック（最もよく使う）

```bash
python3 voronoi_checker.py <フォルダパス>
```

### 単一ファイルのチェック

```bash
python3 voronoi_checker.py <ファイル.pdf>
```

### オプション一覧

| オプション | 説明 | デフォルト |
|---|---|---|
| `--threshold N` | N 未満をフラグ対象にする | `29` |
| `--out ファイル名.xlsx` | 結果を Excel に保存 | なし（コンソール出力のみ） |
| `--debug` | 検出結果を画像で `./debug/` フォルダに保存 | なし |

### 実行例

```bash
# 提出フォルダを閾値29でチェックして Excel 保存
python3 voronoi_checker.py \
  "/path/to/IT10_Submission_folder" \
  --threshold 29 \
  --out ~/Downloads/voronoi_result.xlsx

# 単一ファイルを確認
python3 voronoi_checker.py report.pdf --threshold 29

# 検出画像も確認したい場合
python3 voronoi_checker.py /path/to/folder --debug
```

## 結果の見方

実行するとコンソールに以下の形式で出力されます。

```
[01/18] report.pdf ... page5  セル:19(visual) マーカー:12 ★両方不足 [要確認]
[02/18] report2.pdf ... page5  セル:68(text) マーカー:23
```

### 判定マーク

| マーク | 意味 |
|---|---|
| `★両方不足` | セル数・マーカー数が**両方**閾値未満 → 要確認の本命 |
| `⚠セルのみ` | セル数のみ低い → 検出誤差の可能性あり（低優先） |
| （なし） | 問題なし |

### 検出方法の表示

| 表示 | 意味 |
|---|---|
| `(text)` | PDF テキストから件数を読み取り → **信頼度高** |
| `(visual)` | 画像から視覚的に検出 → 誤検出の可能性あり |
| `[要確認]` | テキスト検出ができなかったため手動確認推奨 |

### サマリー出力

```
────────────────────────────────────────────────────────────
【二重判定：両方不足確定（テキスト確認済み）】: 1件
  ✗ report.pdf  セル:10 マーカー:8 (page5)

【二重判定：両方不足（要手動確認）】: 2件
  ? report2.pdf  セル:19 マーカー:12 (page6)
  ? report3.pdf  セル:21 マーカー:17 (page5)

【セルのみ不足・マーカーOK（検出誤差の可能性）】: 1件
  - report4.pdf  セル:12 マーカー:30 (page5)
```

- **両方不足確定**：テキストで件数が確認でき、かつ閾値未満
- **両方不足（要手動確認）**：視覚検出のみで両方低い → 優先的に目視確認
- **セルのみ不足**：マーカーは OK なので検出誤差の可能性大

## 注意事項

- 地図上に重ねたボロノイ図はマーカーの形（ピン・十字・丸）によって検出精度が変わります
- PDF テキストに発生点数が明記されている場合（例：`"I set 68 AED locations as generators"`）は自動で正確に読み取ります
- `★両方不足` のファイルを優先的に目視確認することをお勧めします
- PPTX ファイルは LibreOffice がインストールされている場合のみ対応
